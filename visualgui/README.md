# VisualGUI

Приложение для визуального просмотра GUI из библиотеки libx.so.

## Описание

VisualGUI - это Android приложение, которое позволяет визуально просматривать и тестировать интерфейс из вашей библиотеки. Приложение использует OpenGL ES 3.0 и Dear ImGui для рендеринга GUI.

## Структура проекта

```
visualgui/
├── app/
│   ├── src/main/
│   │   ├── cpp/           # Нативный код C++
│   │   ├── java/          # Java код Android
│   │   ├── res/           # Ресурсы Android
│   │   └── AndroidManifest.xml
│   └── build.gradle
├── build.gradle
└── settings.gradle
```

## Требования

- Android Studio Hedgehog (2023.1.1) или новее
- Android SDK 34
- Android NDK r25b или новее
- CMake 3.22.1 или новее
- Gradle 8.0

## Сборка

### Способ 1: Через Android Studio

1. Откройте проект в Android Studio
2. Дождитесь синхронизации Gradle
3. Подключите Android устройство или запустите эмулятор
4. Нажмите "Run" (зеленая стрелка)

### Способ 2: Через командную строку

```bash
# Перейдите в директорию проекта
cd visualgui

# Сборка debug версии
./gradlew assembleDebug

# Сборка release версии
./gradlew assembleRelease
```

APK файл будет создан в:
- `app/build/outputs/apk/debug/app-debug.apk`
- `app/build/outputs/apk/release/app-release.apk`

## Установка

```bash
# Установка на устройство
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Функции

Приложение отображает полный GUI с следующими вкладками:

1. **Aimbot** - настройки авто прицеливания
   - Включение/выключение
   - Настройка FOV
   - Выбор костей для прицеливания
   - Настройка скорости и шанса попадания

2. **Visuals** - визуальные настройки ESP
   - Отображение боксов вокруг игроков
   - Health bar и количество здоровья
   - Имена и иконки оружия
   - Скелет и линии

3. **Exploits** - игровые эксплойты
   - Настройки оружия
   - Бомба
   - Премиум функции
   - Движение

4. **Skins** - редактор скинов
   - Список доступных скинов
   - Редактор параметров скинов

5. **Config** - управление конфигурациями
   - Сохранение/загрузка конфигов
   - Список доступных конфигураций

6. **Settings** - общие настройки
   - Отображение FPS
   - Anti-screenshot
   - Panic mode

## Управление

- **Перетаскивание окна** - зажмите и перемещайте заголовок окна
- **Изменение размера** - потяните за угол окна
- **Вкладки** - нажмите на название вкладки для переключения
- **Чекбоксы** - нажмите для включения/выключения опции
- **Слайдеры** - перетаскивайте для изменения значения
- **Кнопки** - нажмите для активации

## Технические детали

### Используемые технологии

- **Dear ImGui** - библиотека для создания GUI
- **OpenGL ES 3.0** - графический API для рендеринга
- **EGL** - интерфейс между OpenGL и оконной системой Android
- **NDK** - нативный код C++

### Архитектура

```
MainActivity (Java)
    ↓
GLSurfaceView + Renderer
    ↓
NativeBridge (JNI)
    ↓
main.cpp (C++)
    ↓
GUI/ESP/Aimbot классы
    ↓
ImGui + OpenGL ES
```

## Кастомизация

### Изменение стиля

Стили GUI определены в `GUI.cpp` в методе `ApplyStyle()`. Вы можете изменить:

- Цвета интерфейса
- Радиус скругления окон
- Размеры элементов
- Шрифты

### Добавление новых элементов

Для добавления новых элементов в GUI:

1. Отредактируйте соответствующий метод `Draw*Tab()` в `GUI.cpp`
2. Добавьте новые переменные конфигурации в соответствующие структуры

## Устранение неполадок

### Ошибка: "CMake not found"
- Установите CMake через SDK Manager в Android Studio

### Ошибка: "NDK not found"
- Установите NDK через SDK Manager
- Пропишите путь к NDK в `local.properties`:
  ```
  ndk.dir=/path/to/ndk
  ```

### Приложение вылетает при запуске
- Проверьте логи через `adb logcat`
- Убедитесь что устройство поддерживает OpenGL ES 3.0

### Ошибки сборки нативного кода
- Очистите проект: `./gradlew clean`
- Удалите папку `.cxx` и пересоберите
